## 01 ISSUE — 섞는 대신, 같은 풍경을 바라보게
이미지: images/01_issue.jpg

- **갈등 — 섞어 두면:** 선택권 없는 근접 — 시선이 닿고 마찰이 생긴다 (1.2~3.7m)
- **배제 — 그래서 사람을 나눈다:** 카페 출입문 "60세 이상 출입제한" (2023) / 공공 수영장에도 노시니어존 요구 (2024) / 노키즈존 전국 500곳 이상 (2023)
- **공존 — 같은 나무를 바라보면:** 인사할 의무 없는 거리에서 같은 풍경을 겪는다 (약 8~13m) → 배제 대신, 거리를 각자 고른다

## 06 STRATEGY — 얼마나 다가갈지는 각자 고른다
이미지: images/06_strategy.jpg
- 인용: "Triangulation — the process by which some external stimulus provides a linkage between people and prompts strangers to talk to each other as if they were not." — William H. Whyte
- → 이 건물에서는 나무가 그 외부 자극이다. 눈을 마주칠 부담 대신, 같은 것을 보고 있다는 감각.
- 방 안: 앉아서도 보이드가 보인다
- 문턱 (1.5m): 나와서 기대는 곳 (유리 난간 1.2m)
- 보이드: 마주 보는 방 10.7~13.5m
- **보이드는 인사하지 않아도 되는 거리** — 나무 아래 마당 1~3m (다가가기는 선택) / 문턱 끝끼리 −3m / 방 ↔ 방 10.7~13.5m
- 거리 구분: 0m 친밀·개인 / 1.2m 사회적 / 3.7m 공적(근) / 7.6m~ 공적(원) — 관여할 의무가 없다

## 07 MASS PROCESS — 분리는 매스가, 공존은 지붕과 보이드가
이미지: images/07_mass_process.jpg
1. 최대 볼륨 — 건축 가능 영역
2. 비운다 — 가운데 보이드, 북측 필로티
3. 나눈다 — 세대별 볼륨
4. 덮는다 — 각자의 방, 하나의 지붕 아래
5. 연다 — 문턱 1.5m · 통유리

## 08 ZONING — 층마다 다른 세대, 가운데 하나의 보이드
이미지: images/08_zoning.jpg
- 층 레벨: B1 FL -4.4 / 1F FL ±0.0 / 2F FL +4.5 / 3F FL +8.1 / 4F FL +11.7
- 범례: 10대 · 2030 · 4050 · 60+ · 시간제 공용 · 코어·서비스 · 옥상·테라스 · 보이드·나무
- **각자의 공간, 하나의 지붕 — 세 가지 장치**
  - 영역의 구분: 세대별 주점유 영역을 층과 레벨로 나눈다
  - 시선의 중심 공유: 서로가 아니라 가운데 나무를 본다
  - 일상의 배경화: 다른 세대가 마찰이 아닌 살아가는 풍경이 된다
