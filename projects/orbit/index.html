01. ANALYSIS & STRATEGY

대지 분석 및 사용자 전략

01. Site Condition (대지 현황)

SITE OVERVIEW (대지 개요)

• Location: 경기도 성남시 수정구 창곡동 591번지

• Area: 286.30 ㎡

• Zoning: 제1종 전용주거지역

• Scale: 건폐율 50%, 용적률 100%

URBAN CONTEXT (도시적 맥락)

• The Urban Link (도시적 연결): 북측의 공원과 남서측의 상업지구 사이에 위치하여, 주거의 쾌적함과 도시의 활력을 잇는 가교 역할.

• Infrastructure (인프라): 단지 내 보행로는 공원 산책로와 연결되며, 인접한 남위례역을 통해 도심 접근성이 우수한 교통의 교차점.

• Balance (균형): 자연의 여유와 도시의 편의가 공존하는 입지적 특성을 반영하여, 외부와 소통 가능한 주거 환경을 제안함.

02. Site Analysis (대지 분석)

KEY ISSUES (현황 분석)

• The Dilemma (딜레마): 대지의 유일하게 트인 면인 도로변은 개방감을 줄 수 있는 장점이지만, 동시에 행인들의 시선에 노출되어 프라이버시 침해가 우려됨.

• Openness vs. Privacy (개방감과 사생활의 충돌): 2층 서재에서는 밖을 내다보고 싶지만, 밖에서는 안이 보이지 않아야 하는 모순적인 조건이 필요함.

DESIGN STRATEGY (해결 전략)

• Brick Screen (벽돌 스크린): 완전히 막힌 벽 대신, 구멍이 뚫린 영롱쌓기를 도로변에 설치함.

• Visual Filtering (시선 필터링): 안에서는 밖이 보이고, 밖에서는 안이 안 보이는 시각적 필터를 만들어 개방감과 프라이버시를 동시에 해결.

03. User Scenario – Who They Are

#고등학교 동창생 #비혼주의

03. User Scenario – The Time Difference (Conflict & Strategy)

• The Conflict (12시간의 마찰): 새벽 4시에 자는 사람과 4시 반에 일어나는 사람. 하루 중 12시간 이상 활동과 수면이 겹쳐 소음 및 동선 간섭이 발생함.

• Orbit Circulation (순환 궤도): 물리적 거리를 확보하되 순환형 복도로 연결하여, 서로 다른 시간대를 사는 이들이 충돌 없이 공존하는 건축적 장치.

02. CONCEPT & PROCESS

개념 및 형태 생성 프로세스

01. Main Concept — PROJECT CONCEPT : ORBIT

건축적 중력 : 타인을 묶는 보이지 않는 힘

1. The Definition — 오늘날의 가족은 혈연을 넘어 '관계의 지속성'으로 확장되고 있다. 본 프로젝트는 서로 다른 궤적을 그려온 30대 4인이 타인에서 우리가 되어가는 과정을 담는 건축적 그릇이다.

2. The Solution — 우리는 이들이 지속 가능한 유대를 맺기 위해 필요한 것은 억지스러운 통합이 아니라, 서로를 강력하게 끌어당기는 구심점(Core)이라고 정의했다. 이 집은 단순한 거주 공간을 넘어, 흩어지려는 개인들을 안으로 당기는 건축적 중력 장치이다.

3. The Strategy — [CORE]로 모으고, [LOOP]로 순환하며, [NEXUS]로 연결한다. 서로 다른 속도의 삶이 부딪히지 않고 공존하는 우주적 질서를 통해, 타인은 비로소 가족이 된다.

02. Design Strategy : 3 ORBIT LOGICS

LOGIC 1

CORE

Sunken Living

대지 중앙에 30cm 낮춘 원형 선큰 거실을 배치하여, 흩어진 개인들을 안쪽으로 끌어당기는 강력한 심리적 구심점을 형성한다.

LOGIC 2

LOOP

1.4m Circulation Loop

직각의 개인방 사이를 연결하는 곡선형 순환 복도는, 서로 다른 시간대를 사는 거주자들이 좁은 복도에서 충돌 없이 유연하게 교차하는 조율 장치이다.

LOGIC 3

NEXUS

Void & Atrium

1층과 2층을 수직으로 관통하는 아트리움(Void)을 통해 시선이 끊임없이 교차하며, 물리적 거리는 두되 심리적 유대는 유지하는 느슨한 연대를 구축한다.

04. Zoning Diagram : Active Orbit vs. Filtering Layer

1F : ACTIVE ORBIT (동적 순환 궤도)

• Loop Connection: 중앙의 선큰 거실(Core)을 원형 복도가 감싸고, 개별 실들이 이 궤도에 접속하는 구조

• Interaction: 복도는 단순히 지나가는 통로가 아니라, 거실의 활동이 확장되고 각자의 동선이 빈번하게 섞이는 교류의 링(Ring) 역할

2F : FILTERING LAYER

• Buffer Zone: 2층의 복도의 일부는 오픈 서재로 기능하며, 공용 공간(Void)과 사적 공간(Room) 사이의 완충 지대 역할

• Privacy: 1층과 달리, 2층의 궤도는 소음과 시선을 걸러내고 침실의 독립성을 보호하는 장치

• Nexus of Gaze: Living room [core] · Atrium (void) · Dining room · Open library · Room 1~4 · Bathroom

06. Material : RED BRICK

IDENTITY : Red Brick

DETAIL : Honeycomb Screen (영롱쌓기)

• IDENTITY : Red Brick — 시간이 흐를수록 고풍스러운 깊이를 더하는 붉은 벽돌은, 비혈연 공동체의 관계가 층층이 쌓여가는 시간의 적층과 따뜻한 궤도의 정체성을 상징한다.

• DETAIL : Honeycomb Screen (영롱쌓기) — 도로변 2층 매스에 적용된 이중 외피(Double Skin) 시스템.

- Block In (차단): 외부 시선은 벽돌 스크린에 막혀 프라이버시를 완벽하게 보호함.

- View Out (조망): 내부에서는 벽돌 틈 사이로 답답함 없이 외부 풍경을 조망함.
